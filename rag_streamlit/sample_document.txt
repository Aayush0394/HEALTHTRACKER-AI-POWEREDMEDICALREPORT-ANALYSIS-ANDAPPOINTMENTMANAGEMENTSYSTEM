Document RAG Assistant – Sample Knowledge Base
==============================================

About the Project
-----------------
The Document RAG Assistant is an AI-powered conversational application designed to let users interactively upload custom documents (PDF or TXT) and query them in natural language using context-grounded responses.

Key Features
------------
1. Document Loading & Parsing: Supports automated parsing of uploaded PDF and TXT files via temporary file handlers.
2. Configurable Processing: Features adjustable chunk sizes and retrieval depth controls directly in the application sidebar.
3. Semantic Vector Indexing: Splits text with RecursiveCharacterTextSplitter and embeds data using OpenAI's text-embedding-3-small stored in ChromaDB.
4. Grounded Question Answering: Uses gpt-4o-mini with strict system instructions to answer queries strictly based on retrieved document chunks.

Technology Stack
----------------
- Frontend: Streamlit
- LLM: OpenAI gpt-4o-mini
- Embeddings: OpenAI text-embedding-3-small
- Vector Database: ChromaDB
- Framework: LangChain
- Programming Language: Python

Future Scope
------------
- Multi-Document Support: Simultaneous ingestion of multi-format files (DOCX, CSV, MD).
- Cloud Vector Databases: Integration with persistent remote stores like Pinecone or Qdrant.
- Hybrid Search & Re-ranking: Combining BM25 keyword search with vector search and cross-encoder re-ranking.
- Local LLM Privacy: Adding Ollama / Llama-3 support for 100% offline enterprise deployment.
